### 规范取舍

- 我非常讨厌单个名字内部出现空格的情况，对于像Da（达） De（德）Del（德尔） Du（杜） La（拉） Le（勒） Van（范） Den（登） Di（迪）Ste.（圣） Des（德斯）等小品词，后续翻译都应该取消以前那种联合翻译的做法，采用单独翻译。取消前缀小品词之后发现后面的名字已经有了的就会删去，如果没有的会增补。


### NOTICE
- 小品词是没有性别区分功能的，比如说Lia对应莉娅，De Lia应该对应德莉娅，原手册不知出于何种原因（个人不做过多揣测）将 Delia 推荐翻译为 迪莉娅，因为这一般是一个女名，但这种做法应该废弃，都统一为德。Delia翻译为德莉娅，但个人精力有限原手册的这些内容不做更改了。

- 原手册里面的小品词加上某个名字的情况有的会省略中间的空格作为一个单词进入，在翻译上如果需要联合翻译，那么应该是规范的小品词前缀加上后续手册对应的名字，原手册在联合翻译的情况有些是没有遵循这个原则的，个人精力有限没有对原手册这些内容做更改。新的翻译应该遵循上述的统一规范，比如说 Sage 是 萨奇 原手册的Lesage 被翻译为 勒萨热，按照统一规范应该推荐翻译为 勒萨奇。（从翻译的角度是不可能做到读音完全一模一样的，即使是英语母语人士在读那些外来名字发音也不会强求一定要和外来源读音相同，因此完全没有必要把事情弄复杂，做到英语读音一致即可。至于这个词，我听了一下sage的法语读音也听不出来一定要翻译为萨热的道理。）
